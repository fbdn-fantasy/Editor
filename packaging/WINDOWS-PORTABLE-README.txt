Editor for Windows 11 x64

Extract the entire ZIP to a writable folder, then open Editor.exe. You can also
drag files onto Editor.exe or pass their paths on the command line.

Editor keeps its settings, window position, recovery records and WebView2 data
in the Data folder next to Editor.exe. Close Editor before moving the folder
or disconnecting its drive. When upgrading, keep the existing Data folder.

The application uses the Microsoft Edge WebView2 Runtime supplied with Windows
11. On machines where it has been removed, install the x64 Evergreen Runtime
from Microsoft's WebView2 download page before opening Editor.
